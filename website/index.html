AniMusic

A free music player for Android, macOS, Windows and Linux.
Bring your playlists from any music app. No ads, no account needed.

Download View source

Features

Import from any music app

  • Paste or share a link from Spotify, Apple Music, Deezer, YouTube / YT Music, JioSaavn, SoundCloud, Tidal, Qobuz, Audiomack, Gaana, ListenBrainz or song.link.
  • Smart matching checks every song by title, artist, version and length, and lets you review unsure matches.
  • Import files: CSV (Exportify, TuneMyMusic, Google Takeout), M3U/M3U8 or TXT, or paste a list of songs.
  • Sync from source, import history, and export as M3U, CSV or text.

Playback

  • Search, browse and play anything on YouTube Music.
  • Hi-Res lossless audio (FLAC/ALAC) from a module source, with YouTube Music as fallback.
  • Gapless playback with true crossfade, 0 to 12 s, and Automix DJ-style transitions (beta).
  • Offline downloads and your local music library.

Accounts and sharing

  • Sign in with Google for your own library and recommendations.
  • Spotify integration: play your Spotify playlists and Liked Songs.
  • Listen Together: listen in sync with friends.
  • Discord Rich Presence, plus scrobbling to Last.fm and ListenBrainz.

Looks and feel

  • Word-synced lyrics from many providers, with smooth animation.
  • Animated album canvas on the now-playing screen.
  • Dynamic theming from the album art.
  • Sleep timer, equalizer, playback speed, per-network quality and 16 languages.

Install help

AniMusic isn't in an app store, so your device asks you once to trust it. That's normal for free apps from GitHub.

Android
  1. Download the APK: arm64-v8a for almost every phone, or universal if you're not sure.
  2. Open the downloaded file. If Android asks, allow your browser to Install unknown apps, then go back and tap Install.
  3. If Play Protect warns that the app is unknown, tap More details → Install anyway. It warns because the app isn't from the Play Store.
  4. Later updates come inside the app: when a new version is out, AniMusic shows an update dialog. Tap Download Now, then Install Now.
macOS
  1. Pick the file for your Mac's chip. Not sure? Click the Apple menu → About This Mac. "Chip: Apple M1/M2/M3/M4…" means Apple Silicon. "Processor: Intel…" means Intel.
  2. On Intel Macs everything works, except that Automix mixes without beat-matching.
  3. Open the .dmg and drag AniMusic into Applications.
  4. The first time, right-click (or Control-click) AniMusic in Applications and choose Open, then Open again. After that it opens normally.
  5. If macOS says AniMusic "is damaged and can't be opened" or there's no Open button, open Terminal and run this once:
    xattr -cr /Applications/AniMusic.app
    Then open AniMusic again. (The app isn't signed with a paid Apple developer account, so macOS marks it as downloaded from the internet. This command removes that mark.)
Windows
  1. Download Windows installer (.exe) and run it.
  2. If Windows shows "Windows protected your PC", click More info → Run anyway. It appears because the app isn't signed with a paid certificate.
  3. No admin rights? Use the portable .zip: unzip it anywhere and run AniMusic.exe inside.
  4. The .msi is the same app for IT-managed PCs.
Linux
  1. AppImage (any distro): make it runnable and start it.
    chmod +x AniMusic-*-linux-x86_64.AppImage && ./AniMusic-*-linux-x86_64.AppImage
    If it complains about FUSE, install FUSE 2: sudo apt install libfuse2t64 on Ubuntu 24.04 and newer, sudo apt install libfuse2 on older versions.
  2. Debian / Ubuntu: sudo apt install ./AniMusic-*-linux-amd64.deb
  3. Fedora / openSUSE: sudo dnf install ./AniMusic-*-linux-x86_64.rpm
